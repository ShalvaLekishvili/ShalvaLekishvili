## v4 → v5 change

v4 was a polished static portfolio.

v5 is a **portfolio system**:
- dual-theme local visuals;
- self-updating GitHub intelligence;
- public-claim verification;
- machine-readable evidence manifest;
- unit tests;
- profile validator;
- full-SHA-pinned workflows;
- Dependabot for Actions;
- CODEOWNERS;
- explicit baseline/failure semantics;
- no core dependency on external stats widgets;
- all 14 credentials visible;
- reviewer-specific navigation.

## Portfolio anti-patterns intentionally removed

- fake skill percentages;
- giant tool-wall as the primary identity;
- follower/star counts as competence signals;
- excessive neon "hacker" aesthetics;
- hidden certifications;
- opaque third-party GitHub metrics as core evidence;
- unpinned third-party workflow actions.
